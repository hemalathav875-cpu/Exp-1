## Exp-1 ATM & BANKING SYSTEM
## REGISTER NO:212225230099
## DATE:17/11/26
## IM:
To develop an ATM and Banking System to perform basic banking operations like deposit, withdrawal, and balance enquiry.

## SRS (Procedure):
1.Start the ATM and Banking System. 2.Enter the account number and PIN to log in. 3.Verify the user details for secure access. 4.Display the main menu with different banking operations. 5.Select the required operation, such as balance enquiry, deposit, or withdrawal. 6.Enter the amount for deposit or withdrawal. 7.Update the account balance after completing the transaction. 8.Display the updated balance and transaction details. 9.Allow the user to perform another operation or exit the system. 10.Stop the program after the user logs out.
